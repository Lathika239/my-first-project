🚗 Smart Parking System

A Python-Based Smart Parking Management Application

Welcome to my Smart Parking System project! This project was developed as part of a one-day hackathon, where I worked as a team member to explore how software can improve parking management.

💡 About the Project

Finding and managing parking spaces can be challenging. This project explores a software-based approach to organizing vehicle registration, parking slot allocation, pre-booking, vehicle history, and payment management in one application.

✨ Key Features

- 🚘 Vehicle Registration — Manage vehicle details.
- 🅿️ Parking Slot Management — Organize parking slot allocation.
- 📅 Pre-Booking — Support advance parking arrangements.
- 📋 Vehicle History — Review previous parking records.
- 💳 Payment Management — Support parking payment workflows.
- 🖥️ Desktop Interface — Built with Python and Tkinter.

🛠️ Technologies Used

- Language: Python
- GUI: Tkinter
- Database: SQLite
- Additional Libraries: qrcode, Pillow

⚙️ Getting Started

Requirements

- Python 3
- Required Python libraries

Installation

Install the additional libraries using Command Prompt:

pip install "qrcode[pil]" pillow

Run the Application

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the required dependencies.
4. Run "smart_parking_system.py" using Python.
